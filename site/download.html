Re:Cast is free software, and so are most of the programs inside it. The source code of the ones under the GPL and LGPL (Unicorn, FFmpeg and pygame-ce) is in KH-ReCast-sources.zip; the list of everything the apps include is in the credits.

Not sure which Mac you have? Apple menu → About This Mac: “Chip: Apple M…” means Apple Silicon, “Processor: Intel” means Intel.

Stuck, or something went wrong? Email khrecast@gmail.com or leave an entry in Jiminy's Journal.

Checking that your download is genuine (SHA-256)

The installers are not code-signed, so compare the file's SHA-256 hash with these, which are also in SHA256SUMS.txt and on GitHub. If they differ, don't run it: download it again, from the other place if you can.

Windows (PowerShell): Get-FileHash .\KH-ReCast-Windows-x64.exe · macOS: shasum -a 256 KH-ReCast-macOS-arm64.zip · Linux: sha256sum KH-ReCast-Linux-x86_64.run

Windows says “Windows protected your PC”

The installer isn't code-signed, so Windows' SmartScreen is cautious about it. Click More info, then Run anyway. It installs only for your user account and never asks for administrator rights. To remove it later, use Settings → Apps.

Mac says the app can't be opened
  1. Unzip the download and drag Kingdom Hearts Re-Cast into Applications.
  2. Right-click (or Control-click) the app, choose Open, then Open again. You only do this once.
  3. If it says the app is “damaged”, open Terminal and run:
    xattr -dr com.apple.quarantine "/Applications/Kingdom Hearts Re-Cast.app"
Installing on Linux

Download the .run file for your computer, then in a terminal:

sh KH-ReCast-Linux-x86_64.run

It installs for your user only (no sudo) and adds Kingdom Hearts Re:Cast to your applications menu. To remove it: sh KH-ReCast-Linux-x86_64.run --uninstall. It needs a desktop Linux using glibc 2.28 or newer (not Alpine). On a 64-bit ARM machine, use the aarch64 file instead.

Installing on Android
  1. Download KH-ReCast-Android.zip on the phone (on a Chromebook or an Android emulator, take KH-ReCast-Android-x86_64.zip instead) and extract it (in the Files app, tap the zip, then Extract). You get KH-ReCast-Android.apk and a KH-ReCast-game folder.
  2. Tap KH-ReCast-Android.apk. The first time, Android asks you to allow installing apps from your file manager: allow it, then tap Install.
  3. Open Re:Cast and choose smartphone or flip phone style. When it asks for the game files, tap Set up the game files and pick the KH-ReCast-game folder. The app copies them into its own storage, so you can delete the zip and the folder afterwards.

Your saves stay in the app: uninstalling it deletes them, so export them first from the app's Saved games screen. The phone's compressed sound effects play through Android's own decoder; if your phone plays the music but not the sword and hit sounds, please tell us which phone it is in Jiminy's Journal. It runs on Android 7 or newer, including the newer phones that use 16 KB memory pages. If you already have version 0.1.0, installing the new file over it keeps your saves.
